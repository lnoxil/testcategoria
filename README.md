# Тесты по транспортной безопасности (Python + Flask)

Сайт для подготовки к экзамену:
- **Общий тест**: случайные **50 вопросов** списком на одной странице.
- **Быстрый тест**: **20 вопросов**.
- **Тест над ошибками**: формируется автоматически из вопросов, где были ошибки.
- После выбора варианта ответ фиксируется (изменить нельзя), вопрос и ячейка справа сразу окрашиваются в зелёный/красный.
- Справа есть панель 1..N с цветовым статусом ответов.
- На главной показывается аналитика: средний процент по тестам на 50 вопросов и топ вопросов с ошибками.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть: `http://127.0.0.1:5000`

## Тесты

```bash
python -m unittest tests/test_app.py
```

## Данные

Вопросы хранятся в `data/questions.json`, прогресс и аналитика — в `data/user_stats.json`.
