# Тесты по транспортной безопасности (Python + Flask)

Сайт для подготовки к экзамену:
- **Общий тест**: случайные **50 вопросов**.
- **Тест над ошибками**: формируется автоматически из вопросов, где были ошибки.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть: `http://127.0.0.1:5000`

## Тесты

```bash
python -m unittest tests/test_app.py
```

## Данные

Вопросы хранятся в `data/questions.json`.

Внесены правки по вашим замечаниям, включая:
- №111: правильный ответ **«тренажерная»**.
- №113: правильный ответ **«1 раз в 3 года»**.
- №124: правильный ответ **«90%»**.
- Добавлены вопросы **132–147** и **154–159**.
