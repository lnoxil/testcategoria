# Тесты по транспортной безопасности (Python + Flask)

Сайт для подготовки к экзамену:
- **Общий тест**: случайные **50 вопросов** в формате списка на одной странице.
- **Тест над ошибками**: формируется автоматически из вопросов, где были ошибки.
- После выбора варианта сразу показывается: ответ верный или неверный.
- Справа отображается панель из ячеек (1..50), ячейка вопроса окрашивается: зеленый = верно, красный = неверно.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть: `http://127.0.0.1:5000`

## Тесты

```bash
python -m unittest tests/test_app.py
```

## Данные

Вопросы хранятся в `data/questions.json`.

Внесены правки по вашим замечаниям, включая:
- №111: правильный ответ **«специальная»**.
- №113: правильный ответ **«1 раз в 5 лет»**.
- №124: правильный ответ **«90%»**.
- Добавлены вопросы **132–147**, **154–159**, **160–162, 164–189** и **190–200, 202–210**.
