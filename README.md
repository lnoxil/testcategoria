# Тесты по транспортной безопасности (Python + Flask)

Сайт для подготовки к экзамену:
- **Общий тест**: 50 вопросов.
- **Тест над ошибками**: формируется автоматически из вопросов, где были ошибки.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте: `http://127.0.0.1:5000`

## Данные

Вопросы хранятся в `data/questions.json`.

Исправления по вашим замечаниям уже внесены, включая:
- вопрос **111**: правильный ответ **«тренажерная»**;
- вопрос **113**: правильный ответ **«1 раз в 3 года»**;
- вопрос **124**: правильный ответ **«90%»**.
