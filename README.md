# Тесты по транспортной безопасности (Python + Flask)

Сайт для подготовки к экзамену:
- **Общий тест**: случайные **50 вопросов** списком на одной странице.
- **Быстрый тест**: **20 вопросов**.
- **Тест над ошибками**: включает все накопленные ошибки из прошлых тестов.
- После выбора варианта ответ фиксируется (изменить нельзя), вопрос и ячейка справа сразу окрашиваются в зелёный/красный.
- Справа панель 1..N с цветовым статусом ответов и быстрым переходом к вопросу.
- На главной показывается аналитика:
  - средний процент по тестам на 50 вопросов,
  - вопросы, где больше всего ошибок,
  - график прогресса по дням (рост процента, снижение ошибок).

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

По умолчанию сервер запускается на `0.0.0.0:5000` в HTTP режиме.

- На компьютере: `http://127.0.0.1:5000`
- На телефоне (та же Wi‑Fi): `http://<IP_КОМПЬЮТЕРА>:5000`

IP компьютера:

```bash
hostname -I
```

## HTTPS режим (опционально)

Если нужен HTTPS:

```bash
USE_HTTPS=1 python app.py
```

Если появится ошибка `Using ad-hoc certificates requires the cryptography library`, установите зависимости:

```bash
pip install -r requirements.txt
```

Приложение также имеет fallback: при невозможности поднять adhoc HTTPS автоматически запустится HTTP.

## Почему были ошибки 400 в логах
Ошибка `Bad request version` в Flask означает, что в HTTP-сервер пришёл TLS/HTTPS трафик.

Решение:
- либо открывать `http://...` при HTTP-режиме,
- либо запускать `USE_HTTPS=1` и открывать `https://...`.
